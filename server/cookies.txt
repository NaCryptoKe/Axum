## ⚙️ **User Activity & Presence**

### `PATCH /@:username/status`

**Purpose:** Manually update a user’s online/offline status.
(Useful when WebSocket integration isn’t yet live.)

**Request:**

```json
{
  "online": true
}
```

**Response:**

```json
{
  "message": "Status updated successfully",
  "username": "nahom",
  "online": true,
  "lastSeenAt": "2025-11-06T09:00:00Z"
}
```

---

### `GET /users/last-seen`

**Purpose:** Return a list of users with their last online timestamps.

**Response:**

```json
[
  { "username": "nahom", "lastSeenAt": "2025-11-06T09:00:00Z" },
  { "username": "melvin", "lastSeenAt": "2025-11-05T22:15:00Z" }
]
```

---

## 📝 **User Settings & Profile Management**

### `PATCH /@:username/update`

**Purpose:** Update profile info (bio, avatar, display name, etc.).
Requires authentication.

**Request:**

```json
{
  "display_name": "Nahom The Great",
  "bio": "Just vibing with Axum and React.",
  "avatar_url": "https://cdn.example.com/avatar.jpg"
}
```

**Response:**

```json
{
  "message": "Profile updated successfully",
  "user": {
    "username": "nahom",
    "display_name": "Nahom The Great",
    "bio": "Just vibing with Axum and React.",
    "avatar_url": "https://cdn.example.com/avatar.jpg"
  }
}
```

---

### `DELETE /@:username`

**Purpose:** Soft-delete a user (mark as deleted, don’t actually drop from DB).

**Response:**

```json
{
  "message": "User deleted successfully",
  "deleted": true
}
```

---

## 🔒 **Session Management**

### `GET /auth/sessions`

**Purpose:** Show all active sessions for a logged-in user (detect multiple logins).
Later, you can integrate IP/device tracking here.

**Response:**

```json
[
  {
    "session_id": "uuid",
    "ip": "192.168.0.10",
    "device": "Firefox on Linux",
    "created_at": "2025-11-06T08:30:00Z",
    "active": true
  }
]
```

---

### `DELETE /auth/sessions/:session_id`

**Purpose:** Manually log out a specific session.

**Response:**

```json
{
  "message": "Session revoked successfully"
}
```

---

